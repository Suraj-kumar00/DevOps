Large language models change the operational picture: requests are expensive and slow compared with a typical API call, outputs are non-deterministic, and quality can regress without any code change. This track covers the practices and tools for running LLM applications in production.

## Before you start

Read the [AI Infrastructure](/docs/ai-infra) track first if you plan to self-host models. If you only call managed model APIs, the DevOps observability basics are enough to begin.

## What you will be able to do

- Choose between managed model APIs and self-hosted models for a given use case.
- Evaluate an LLM application and catch regressions before release.
- Trace and measure LLM calls, including tokens, latency and cost.
