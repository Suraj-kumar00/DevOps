DevSecOps makes security part of every stage of delivery instead of a gate at the end. This track focuses on the controls that matter most for cloud native systems: what goes into your artifacts, what is allowed to run, and how you notice when something goes wrong.

## Before you start

The containers, Kubernetes and CI/CD pages in the [DevOps track](/docs/devops) are assumed.

## What you will be able to do

- Secure the path from source code to a running container.
- Enforce cluster policies and keep secrets out of code.
- Detect suspicious behavior at runtime.
