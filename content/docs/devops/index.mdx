DevOps is a way of working that shortens the path from a code change to running software, and makes that path safe to travel often. This track covers the practices and the tools most teams use for it, in the order they build on each other.

## Before you start

Linux, networking and Git from the [Foundations track](/docs/foundations) are assumed.

## What you will be able to do

- Package and run applications in containers and on Kubernetes.
- Build a pipeline from commit to production with CI/CD and GitOps.
- Manage infrastructure as code, and observe what you run.
