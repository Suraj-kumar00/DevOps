MLOps is about getting models out of notebooks and keeping them healthy in production. This track looks at it from the infrastructure side: the pipelines, tracking systems and platforms that make training reproducible and deployment routine.

## Before you start

Containers and Kubernetes basics from the [DevOps track](/docs/devops) help, because most of the tools here run on Kubernetes.

## What you will be able to do

- Map the stages of the ML lifecycle to the tools and teams that own them.
- Run reproducible pipelines and track experiments and models.
- Monitor models in production and know when they need retraining.
